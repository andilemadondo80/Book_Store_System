# Book_Store_System
This is a Bookstore web application
Project Overview

The Online Bookstore System is a web-based application designed to provide users with a convenient and user-friendly platform for browsing, discovering, and purchasing books online. Developed using HTML, CSS, and JavaScript in Visual Studio Code, the system combines an intuitive interface with interactive shopping functionality.

Users can explore different book genres, add books to their shopping cart, review their selected items, and access available online payment methods through a streamlined shopping experience.

Features

Book Catalogue: Browse a collection of books with titles, authors, descriptions, and prices.

Multiple Book Genres: Explore different categories, including fiction, romance, mystery, fantasy, science fiction, biographies, business, self-development, and educational books.

Add to Cart: Add books to the shopping cart and manage selected items before checkout.

Shopping Cart Management: Review selected books, adjust quantities, remove items, and calculate the order total.

Online Payment Options: Provides a checkout interface with supported online payment methods.

Dynamic User Interface: JavaScript powers interactive elements and updates relevant shopping information.

Responsive Design: A layout designed to provide a usable experience across desktop, tablet, and mobile screens.

User-Friendly Navigation: Browse the catalogue and move between shopping and checkout sections with ease.

Technologies Used

HTML5 – Provides the structure and content of the application.

CSS3 – Handles styling, layouts, responsive design, and visual presentation.

JavaScript (ES6+) – Implements interactive features, shopping cart operations, and checkout functionality.

Visual Studio Code – Used as the development environment.
